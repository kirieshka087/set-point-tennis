# SET POINT

Лендинг теннисной школы для детей и взрослых

Демонстрационный проект с оригинальными иллюстрациями, адаптивной вёрсткой и плавными интеракциями

Телефон, тренеры, отзывы и цены используются как контент концепта

## Публикация

Статический сайт публикуется через GitHub Pages из корня ветки `main`
